 StellPlay Mobile (Android) 패치노트 (Patch Notes)

[v 1.11] - 2026.10.22
--------------------------------------------------
1. 앱 재설치 없는 무설치 실시간 웹 에셋 라이브 업데이트 (OTA - Over-The-Air) 시스템 구축
   - 신곡 추가, 곡명/순서 교정, 사비 구간 수정, UI/CSS/JS 개선 등 일상적 업데이트는 APK 재설치 없이 백그라운드에서 실시간 자동 패치되어 즉시 적용
   - 앱 설정 뷰 내 '앱 버전 및 실시간 업데이트' 대시보드 신설 (현재 실시간 패치 버전 확인, 업데이트 지금 확인, 초기 번들 버전 복원 기능 제공)
   - 새로운 패치 다운로드 완료 시 상단 플로팅 배너 알림을 통해 원클릭으로 즉시 새로고침 적용 지원
2. 네이티브 바이너리 변경 시 인앱 원클릭 APK 설치 지원
   - FileProvider 및 REQUEST_INSTALL_PACKAGES 연동으로 외부 브라우저를 거치지 않고 앱 내에서 즉시 최신 APK 다운로드 및 Android 시스템 패키지 설치 창 자동 호출
3. 4기생 정규 오리지널 곡 및 최신 커버곡 전면 반영
   - 4기생 단체 오리지널 곡 '별이 시작되는 곳 (Where Stars Begin)' 한국어 정규 곡명 표준화 탑재
   - 4기생 첫 솔로 커버곡 4곡의 공식 릴리즈 순서(4. 제육감 → 3. 호랑풍류가 → 2. 유령이되고싶어 → 1. 도쿄 테디베어) 완벽 정렬
   - 시라유키 히나 & 아오쿠모 린 듀엣 커버곡 '타상연화' 표준 곡명 복원 및 최신곡 1순위(2026-10-21) 정렬
   - 텐코 시부키 '혁명도중'(2026-10-20) 및 유즈하 리코 'CH4NGE (체인지)'(2026-10-19) 최신 커버곡 신규 수록

[v 1.10] - 2026.10.15
--------------------------------------------------
1. 영상모드 전체화면에서 하드웨어/제스처 뒤로가기 시 화면비 왜곡 버그 해결
   - 영상 모드 전체화면(가로 모드)에서 안드로이드 하드웨어 뒤로가기 버튼 또는 제스처 사용 시 즉시 세로 모드(Portrait)로 안전하게 회전 복귀하도록 개선
   - 웹뷰 레이아웃 리플로우 및 리사이즈 이벤트를 연동하여 전체화면 해제 후 화면비가 찌그러지거나 왜곡되던 현상 완전 해결
2. 재생목록 상세 다운로드 기능 '다중 선택(전체 선택 지원)' 모드로 전면 개편
   - 재생목록 상세 화면의 '다운로드' 버튼 클릭 시 즉시 전곡이 다운로드되던 방식을 대기열과 동일한 세련된 '다중 선택 모드'로 업그레이드
   - 각 트랙별 체크박스 제공, 'N곡 선택됨' 카운터, '전체 선택 / 선택 해제' 토글, '선택 다운로드' 플로팅 바 제공 및 뒤로가기 시 자동 선택 모드 해제 연동
3. 곡 제목 표기 양식 표준화 및 다국어 정돈 (일본어 '원곡명 (번역명)' 통일 & 한국어 곡 영문 부제 제거)
   - 일본어 곡의 제목 양식이 '번역명 (원곡명)' 등으로 뒤섞여 있던 33개 곡을 전수 점검하여 '원곡명 (번역명)' 표준 양식(예: 少女レイ (소녀레이), 千鳥 (물떼새), ヒビカセ (울려퍼져라) 등)으로 일원화
   - 한국어 곡 제목에 불필요하게 병기되어 있던 영문 제목/부제(예: 까탈레나, 아이와 나의 바다, 청록, 야화, 어젯밤도, 불꽃, 개화, 도깨비 꽃 등)를 깔끔하게 순수 한국어로 정돈
   - 한국어 또는 영어로만 기재되어 있던 일본어 보컬로이드/커버 원곡(예: ブレインロット (브레인 롯), 睨めっ娘 (눈싸움), 地球をあげる (지구를 줄게), 夜もすがら君想ふ (밤새도록 널 생각해), おこちゃま戦争 (어린애 전쟁), 偽顔 (가짜 얼굴), フォニイ (포니), ビバハピ (비바해피) 등)의 원곡 일본어 명칭 정상 탑재
4. 안드로이드 홈화면 위젯(4x1, 2x1) 앨범아트 와이드 뷰(Widescreen) 확장
   - 유튜브 기반 16:9 와이드 비율 썸네일 특성에 맞춰 4x1 위젯 앨범아트 너비를 80dp에서 120dp로, 2x1 위젯 앨범아트 너비를 66dp에서 92dp로 확장
   - 비트맵 처리 시 정사각형 1:1 강제 크롭을 중단하고 16:9 비율을 유지하는 와이드 크롭 알고리즘을 적용하여 양옆이 잘리지 않고 캐릭터와 비주얼이 시원하게 보이도록 개선

[v 1.09] - 2026.10.13
--------------------------------------------------
1. 재생목록 곡 순서 편집 시 가장자리(Edge) 연속 자동 스크롤(Continuous Auto-Scroll) 지원
   - 재생목록 상세 화면에서 곡을 드래그한 상태로 화면 상단 또는 하단 가장자리에 손가락을 유지하고 있으면 목록이 지속적이고 부드럽게 자동 스크롤되도록 개선
   - 스크롤 진행 중에도 손가락 아래의 목표 삽입 위치가 실시간으로 재계산되어 드롭 인디케이터가 정확히 추적 표시
2. 뮤직 스테이션 시작 및 사비 메들리 ON/OFF 시 팝업 알림(Toast) 무음화
   - 음악 감상 몰입을 방해하던 뮤직 스테이션 생성 알림 및 사비 메들리 토글 팝업창을 전면 제거하여 조용하고 매끄러운 재생 경험 제공
3. 마시로 뮤지컬 트랙 3D 라이브(live) 카테고리 정상 분류
   - 네네코 마시로의 뮤지컬 무대 곡(Confrontation, 웃는남자, Alive 2, Land of Lola)이 OST 키워드로 인해 OST로 강제 재분류되던 문제를 교정하여 정규 '3D 라이브'로 완벽 분류
4. 곡 정보 수정 실시간 반영 정상화 및 346곡 전수 분위기(Mood) 정밀 큐레이션 탑재
   - 곡 정보 수정 후 메타데이터가 덮어씌워지지 않던 현상을 해결하고, 저장 즉시 대기열 및 모든 뷰에 실시간 반영
   - 분위기 추천에서 누락되던 곡들이 없도록 전체 346곡에 대해 5대 분위기(🔥 파워풀 upbeat, 🌙 감성 chill, ✨ 청량 bright, 🎧 그루비 groovy, 💖 큐트 cute)를 전수 분류하여 분위기 추천 완벽 연동
   - 곡 정보 수정 창에서도 현재 분위기가 정확하게 알약 탭에 선택되어 표시되며, 앞으로 추가되는 곡도 키워드 기반으로 분위기 자동 추천 할당
5. 뮤직 스테이션 시작 시 현재 재생목록(대기열) 자동 열림 & 설명 문구 정돈
   - 곡 옵션 메뉴에서 '뮤직 스테이션 시작' 클릭 시 자동으로 현재 재생 대기열 시트를 열어 생성된 큐를 한눈에 확인할 수 있도록 개선
   - 메뉴 내 불필요했던 '유사곡 무한 연속 재생' 설명 텍스트 제거로 간결화
6. 현재 재생목록(대기열) 다운로드 버튼 '다수 선택 모드' 및 전체 선택 기능 개편
   - 대기열 시트의 다운로드 버튼 클릭 시 바로 전곡이 다운로드되는 대신 '선택 모드'로 진입
   - 대기열 내 원하는 곡만 골라서 다운로드하거나 '전체 선택' 버튼을 통해 손쉽게 일괄 다운로드 가능
7. 오프라인 보관함 카테고리 분류 필터링(전체, 오리지널, 커버곡, 3D 라이브, 피처링&OST) 신설
   - 다운로드된 오프라인 곡 목록 상단에 메인 화면과 동일한 다중 토글 카테고리 필터 칩을 신설하여 원하는 분류별로 모아듣기 지원

[v 1.08] - 2026.10.12
--------------------------------------------------
1. 선택모드 & 재생목록 & 대기열 전곡 오프라인 일괄 다운로드 기능 신설
   - 홈 화면 복수 선택 플로팅 바에 '다운로드' 버튼 신규 탑재 (선택한 다수의 곡을 한 번에 오프라인 저장소로 일괄 보관)
   - 재생목록 상세 화면(좋아요한 곡 및 커스텀 플레이리스트) 헤더에 '다운로드' 액션 버튼 추가
   - 대기열 시트 상단 헤더에 '대기열 다운로드' 액션 추가
   - 스마트폰 화면 폭에 맞춰 텍스트 줄바꿈이나 버튼 겹침이 발생하지 않도록 반응형 플렉스 레이아웃 및 여백 최적화
2. 재생목록 상세 '곡 추가' 버튼 텍스트 정돈
   - 버튼 내 중복 표시되던 '+' 텍스트를 제거하고 깔끔한 아이콘 + '곡 추가' 단일 명칭으로 통일
3. 상단 헤더 사비 메들리 토글 시 테마 스위치 위치 고정
   - 사비 메들리 ON/OFF 전환 시 글자 폭 차이로 인해 우측 다크/라이트 테마 스위치가 좌우로 흔들리던 현상 해결 (너비 78px 고정 및 숫자 폰트 정렬 적용)
4. 대기열 곡 수 표시 배지 및 순번 인덱스 수직 중앙 정렬 교정
   - 대기열 상단 총 곡 수 배지 및 재생목록 번호 텍스트가 위쪽으로 치우쳐 보이던 현상을 수직 정렬로 균형 잡히게 개선
5. 대기열 터치 드래그 상/하단 엣지 자동 스크롤(Edge Auto-Scroll) 및 재생목록 곡 순서 변경 기능 신설
   - 대기열에서 곡 순서를 변경할 때 목록 상단이나 하단 가장자리에 손가락이 접근하면 화면이 부드럽게 자동 스크롤 이동하도록 개선
   - 커스텀 재생목록 및 좋아요 목록에서도 각 트랙에 드래그 핸들을 추가하여 자유롭게 곡 순서를 재배치하고 영구 저장할 수 있도록 지원
6. 곡 정보 추가/수정 팝업 시스템 UI를 앱 내 네이티브 UI로 일원화
   - OS 시스템 팝업 대신 앱 디자인에 맞춘 세련된 인앱 알약(Pill) 셀렉터 및 '오늘' 원터치 날짜 입력 버튼 적용
7. 메인 곡 리스트 빠른 액션 버튼을 '대기열 다음 곡으로 재생'으로 개편
   - 각 트랙 행의 빠른 '+' 버튼을 '▶|'(대기열 다음 곡으로 재생) 버튼으로 교체하여 현재 듣는 곡 바로 다음 순서로 즉시 추가할 수 있도록 개선
8. 미니 플레이어 바 슬라이드 스와이프 제스처 방향 교정
   - 왼쪽에서 오른쪽으로 넘기면 '다음 곡', 오른쪽에서 왼쪽으로 넘기면 '이전 곡'이 재생되도록 스와이프 방향 교정
9. 라이브러리 숨겨진 곡 '선택 복원' 팝업 모달 신규 탑재
   - 모든 곡을 무조건 전체 복원하던 방식에서 벗어나, 숨겨진 곡들의 목록을 확인하고 원하는 곡만 개별 또는 전체 복원할 수 있는 모달 UI 제공
10. 메인 화면 카테고리 필터링 다중 토글 스위치 방식 개편 및 고유 컬러 적용
   - '전체'를 누르면 기본 모드로 리셋되며, 개별 카테고리(오리지널, 커버곡, 3D 라이브, 피처링&OST)를 원하는 조합대로 자유롭게 켜고 끌 수 있는 멀티 필터링 지원
   - 각 필터 버튼 활성화 시 오리지널(보라색), 커버곡(빨간색), 3D 라이브(분홍색), 피처링&OST(파란색) 고유 테마 컬러 적용

[v 1.07] - 2026.10.12
--------------------------------------------------
1. 재생목록(대기열) 현재 재생 곡 순서 위치 표시기 탑재 및 원터치 점프 기능 신규 추가
   - 재생목록 헤더 상단에 현재 재생 중인 곡의 순번과 전체 곡 수를 한눈에 확인할 수 있는 인디케이터 배지(현재 N번째 (N / Total)) 신규 배치
   - 해당 위치 배지 터치 시 재생목록 내 현재 곡 위치로 부드럽게 즉시 스크롤되는 원터치 점프 기능 제공
2. 모바일 대기열 자동 스크롤 오버슈트 및 3~60번째 구간 오차 완전 해결
   - 대기열 리스트 컨테이너 기준 상대 오프셋 계산 누락 및 동적 높이 추정 왜곡으로 인해 특정 구간에서 스크롤이 과도하게 내려가던 현상 원천 해결
   - 리스트 상대 위치 고정(position: relative) 및 아이템 높이 안정화, 뷰포트 정확도 보정으로 재생목록 오픈 시 재생 중인 곡이 정확히 중앙에 오도록 스크롤 정밀도 대폭 향상
3. 신곡 및 기존 곡 발매일(publishedAt/releaseDate) 메타데이터 전수 검증 및 정렬 엔진 안정화
   - 모바일 음원 카탈로그 346곡 전수의 공식 발매일을 유튜브 공식 데이터와 100% 일치하도록 정밀 검증
