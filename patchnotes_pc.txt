[v 1.04] - 2026.10.12
--------------------------------------------------
1. 테마 색상 및 모드 전환 렌더링 성능 대폭 최적화 (60fps/120fps 부드러운 전환)
   - 테마 변경 시 수백 개의 트랙 행(.track-row)에 걸려있던 과도한 CSS 트랜지션을 정돈하여 브라우저 리플로우 및 래스터화 병목 제거
   - 배경 그라디언트 레이어 하드웨어 가속(GPU 격리 transform: translateZ(0), contain: strict) 적용으로 색상 모핑 시 화면 버벅임(Stutter) 원천 해결
   - 멤버 필터 클릭 핸들러에 requestAnimationFrame을 적용하여 즉각적이고 매끄러운 시각 피드백 보장
2. PC 클라이언트 '뮤직 스테이션 (Music Station)' 기능 전격 탑재
   - 모바일 모드의 유튜브 뮤직 스타일 '유사곡 무한 추천 연속 재생' 엔진을 PC 클라이언트 환경에도 전면 적용
   - 미니 플레이어, 전체화면 플레이어 대기열 상단, 슬라이드 대기열 서랍장에 '스테이션' 버튼 신규 탑재
   - 메인 트랙 리스트 퀵 액션에 '뮤직 스테이션 재생' 버튼 추가
   - 검색 상태에서 곡 클릭 시 검색 결과 소수의 곡에 갇히지 않고, 선택한 곡 기반의 전체 라이브러리 유사곡 무한 연속 재생 자동 시작

[v 1.03] - 2026.10.12
--------------------------------------------------
1. 음원 메타데이터 정밀화 및 신규 음원 수집 엔진 강화
   - 시라유키 히나의 신규 OST 'Loop in June (명조:워더링 웨이브 OST)' 공식 등록
   - 영문 서브스트링 충돌(Wuthering ↔ rin)로 인해 히나의 곡이 린의 곡으로 오인식되던 다국어 감지 알고리즘 완전 수정 (단어 경계 및 한글 형태소 단위 분리 검증 적용)
   - 하나코 나나의 최신 커버곡 '브레인 롯 (Brain Rot)' 신규 라이브러리 공식 수록
   - 공식 유튜브 수집 엔진에 '불러보았다', '歌ってみた(우탓테미타)', 'utattemita' 등 다양한 형태의 커버곡 식별 키워드 연동
2. 감성적인 컬러 모핑 및 라이트/다크 모드 전환 트랜지션
   - 멤버별 필터링 버튼 클릭 시 활성 테마 색상 및 발광 효과가 순간 끊김 없이 서서히 부드럽게 바뀌도록 전환 애니메이션(0.35s~0.4s) 고도화
   - 라이트 모드 ↔ 다크 모드 전환 시 배경, 사이드바, 헤더, 모달, 트랙 카드 전반의 색상이 점진적으로 페이드 전환되도록 전역 트랜지션 적용
3. PC 클라이언트 '새 노래 직접 추가' 모달 스크롤 레이아웃 개선
   - '새 노래 직접 추가' 모달에 내부 스크롤 영역(.modal-form-body)을 적용하고 최대 너비를 580px로 확장
   - 4기생 멤버 추가로 인해 길어진 멤버 선택란이 하단에서 잘리지 않고, 곡 수정 메뉴처럼 부드럽게 스크롤되도록 UI 개선
